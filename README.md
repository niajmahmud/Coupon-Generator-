# 🎀 Coupon Generator

A cute and simple web-based Coupon Generator that allows users to create personalized coupons with custom names, descriptions, and validity dates for their family or friends.

## ✨ Features

- 🎟️ Generate personalized coupons.
- 💗 Add custom coupon names and descriptions.
- 📅 Set an expiration date or choose "Forever".
- 🎨 Cute pink-themed design.
- 🖼️ Download generated coupons as PNG stickers.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

coupon-generator/

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/coupon-generator.git
   ```

2. Open the project folder in VS Code.

3. Run `index.html` using Live Server.

4. Start creating your own personalized coupons!
